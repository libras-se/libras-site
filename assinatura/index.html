Como instalar:
  1. Gmail: Configurações → Ver todas as configurações → aba Geral → Assinatura → cole no campo.
  2. Apple Mail: Mail → Configurações → Assinaturas → cole (desmarque "Sempre usar a fonte padrão").
  3. Outlook: Arquivo → Opções → Email → Assinaturas → cole.

Se preferir, use diretamente o arquivo assinatura.html — algumas ferramentas pedem o HTML em vez do conteúdo colado.
